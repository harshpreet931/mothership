# Mothership

**Mission control for your agents.** A native macOS terminal built for the age of coding
agents: vertical-tab workspaces, splits, a built-in browser, and a live view of every
Claude Code, Codex, OpenCode and Gemini session on your machine — with notifications and
one-click permission approvals when one of them needs you.

Built on [libghostty](https://ghostty.org). MIT licensed. macOS 26+.

```sh
swift build && scripts/bundle.sh && open build/Mothership.app
```

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
